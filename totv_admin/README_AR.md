# TOTV+ Admin v3.2 — تطبيق الإدارة الأصلي

تطبيق Flutter أصلي بالكامل، بدون صفحات ويب أو WebView. الشاشات والقوائم والأزرار كلها عناصر أندرويد حقيقية، فلا تكبير ولا تصغير، وحجم الخط ثابت.

## الأقسام

| القسم | ما فيه |
|---|---|
| **الرئيسية** | الطلبات المنتظرة، مفاتيح الصيانة/القفل/الضيوف بضغطة، المشتركون، المخزون، الأكواد، التثبيتات، رسم الطلبات 14 يوماً، توزيع المشتركين |
| **الطلبات** | المنتظرة **مباشرة (Live)** مع صورة الإيصال، قبول وتفعيل تلقائي من المخزون أو يدوي، رفض بسبب، واتساب، كشف الإيصال المكرّر، تجميع حسب اليوم، مراحل الطلب |
| **المخزون** | الهوست الحالي وتغييره للجميع، الوضع ذكي/تعبئة، السعة، النقل التلقائي، حسابات السيرفر (تعديل/إيقاف/حذف/من استخدمه)، إضافة حسابات بلصق رسالة أو يدوياً أو من صورة بالذكاء الاصطناعي |
| **المشتركون** | فعّال، ينتهي قريباً، منتهٍ، كود، يدوي، نشط اليوم، الجدد، مجانيون، تجريبي، محظورون، بحث. ملف كامل لكل مشترك: تمديد، تجديد، إيقاف، حظر، إعادة الوقت المجاني |
| **المزيد** | إشعار فوري (مع كتابة بالذكاء الاصطناعي)، إشعارات المباريات، الأكواد، التفعيل اليدوي، طرق الدفع والأسعار، التحكم بالتطبيق، السيرفرات، الوكلاء، الشكاوى، فحص النظام |

## 🤖 مراقب السيرفرات (البوت الداخلي)

يعمل داخل التطبيق: كل 15 دقيقة والتطبيق مفتوح، وكل 30 دقيقة في الخلفية حتى لو أُغلق التطبيق، ويعود بعد إعادة تشغيل الهاتف.

| يكتشف | ماذا يفعل |
|---|---|
| حساب سيرفر انتهى وعليه مشتركون | يرسل لك إشعاراً، وينقلهم تلقائياً إلى حساب متاح ويحدّث بياناتهم في التطبيق |
| حساب ينتهي خلال 3 أيام أو 24 ساعة | يرسل إشعاراً لتجدده في البنل |
| مقاعد المخزون أقل من الحد | يرسل إشعار «المخزون منخفض» |
| مشتركون بلا حساب متاح | يرسل تنبيهاً لتضيف حسابات |

صفحته في المزيد ← مراقب السيرفرات، وفيها:
- الحالة ورسوم انتهاء الحسابات (14 يوماً) وحالة الحسابات والمقاعد عبر الوقت.
- **سجل** كل ما فعله البوت وكل تفعيل أجريته.
- الإعدادات: العمل في الخلفية، النقل التلقائي، فترة الفحص، حد تنبيه المخزون.

## ⚡ التفعيل من المخزون

- **تجاوز حد السعة:** يفعّل حتى لو امتلأ الحساب (أكثر من 10).
- **اشتراك أطول من صلاحية السيرفر:** يفعّل على حساب ينتهي قبل الاشتراك، والبوت ينقله تلقائياً عند انتهائه.
- **اختيار حساب بنفسي:** قائمة بكل الحسابات مع الضغط والانتهاء.
- إن لم يوجد حساب ضمن الشروط العادية، تظهر أزرار الحل مباشرة بدل الرفض.
- في ملف المشترك: **نقل لحساب آخر** بدون تغيير تاريخ انتهائه.

## 💬 المحادثات (جديد في 3.2)

- **المزيد ← المحادثات:** كل رسائل المستخدمين، مع عدد غير المقروء وإشعار فوري لكل رسالة جديدة.
- **زر «محادثة»** في ملف المشترك، وفي الطلبات، والشكاوى، والفائزين.
- **ردود جاهزة** (زر ⚡) ويمكنك إضافة قوالبك الخاصة.
- **رسائل تلقائية** (المحادثات ← ⚙):
  - عند التفعيل: «تم تفعيل اشتراكك… ينتهي في…».
  - قبل الانتهاء بـ 3 أيام: يرسلها البوت مرة واحدة لكل اشتراك.
  - عند الرد على شكوى أو إغلاقها.

## 🏆 الجوائز والتوقعات (جديد في 3.2)

- **التوقعات:** المستخدم يكتب النتيجة تحت شعار كل نادٍ. التوقع يُفتح قبل الانطلاق بـ 30 دقيقة ويُغلق مع صافرة البداية.
- **النتائج:** بعد نهاية المباراة تكتب النتيجة، فيُحدَّد الفائزون وتصلهم رسالة.
- **الفائزون:** النتيجة الدقيقة تمنح يوماً مجانياً، بزر واحد (تمديد للمشترك، أو تفعيل من المخزون لغير المشترك).
- **الدعوات:** صديق يشترك بكود دعوتك يمنحك 16 يوماً. عند قبول طلب الصديق يسألك التطبيق مباشرة عن منح الجائزة.

## 🛟 شبكة أمان الطلبات

فحص خفيف كل 10 دقائق في الخلفية، لأي طلب لم يصل إشعاره (مثل مستخدمي النسخ القديمة من التطبيق). يمكن إيقافه من «فحص النظام».

### إعداد مرة واحدة للمحادثة والتوقعات
1. Supabase ← SQL Editor: الصق محتوى `supabase/04_engagement.sql` ثم Run.
2. ارفع مجلد `supabase` الجديد، ثم Actions ← **Supabase — Deploy push function** ← Run workflow.
3. تأكد أن `ADMIN_EMAILS` يحوي بريد دخولك في تطبيق الإدارة (مثل `haedirasso@gmail.com,admin@totv.com`).

## لماذا هو أسرع وأوفر

- **دخول مرة واحدة:** Firebase يحفظ الجلسة على الهاتف، وقاعدة الاشتراكات تتجدد تلقائياً. لا يخرج عند إغلاق التطبيق.
- **كل شيء محفوظ على الهاتف:** يفتح فوراً بآخر بيانات، ولا يُعاد التحميل إلا عند ضغطك ⟳ أو سحب الصفحة للأسفل.
- **قراءات Firestore بالحد الأدنى:**
  - الطلبات المنتظرة فقط بمستمع مباشر، وهو يقرأ عند وصول طلب جديد فقط وليس كل ثانية.
  - سجل الطلبات يُقرأ عند التحديث فقط، بحقول خفيفة بدون صور الإيصالات.
  - المشتركون والمخزون والأكواد من قاعدة الاشتراكات (Supabase)، وقراءتها لا تُحسب من حصة Firebase.

## الإشعارات

- **التطبيق مفتوح أو في الخلفية:** كل طلب جديد يظهر فوراً بصوت الكاش من المستمع المباشر. لا يحتاج أي إعداد.
- **التطبيق مغلق تماماً:** يحتاج دالة `push` منشورة (FCM). الإعداد موجود في **المزيد ← فحص النظام**، ويبيّن كل بند ✅/❌ مع طريقة الحل.

### نشر دالة push (مرة واحدة)

1. في المستودع: Settings ← Secrets and variables ← Actions، وأضف:
   - `SUPABASE_ACCESS_TOKEN`: من supabase.com ← Account ← Access Tokens.
   - `FCM_SERVICE_ACCOUNT`: محتوى ملف JSON من Firebase ← Project settings ← Service accounts ← Generate new private key.
   - `ADMIN_EMAILS`: `haedirasso@gmail.com`
2. Actions ← **Supabase — Deploy push function** ← Run workflow.

## البناء

Actions ← **TOTV+ Admin — Build APK**. يبدأ تلقائياً عند أي تغيير في `totv_admin`. بعد الانتهاء نزّل `TOTV-Admin.apk` من Artifacts.

> مجلد `totv_admin/assets` القديم (صفحة الويب) لم يعد مستخدماً، ويمكنك حذفه من المستودع.
