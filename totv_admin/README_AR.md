# TOTV+ Admin — تطبيق الإدارة (أندرويد)

هذا التطبيق هو صفحة الإدارة v6.2 نفسها بكل ميزاتها، داخل تطبيق أندرويد:

- الطلبات، المشتركين، الخطوط، الوكلاء، الأكواد، الإحصائيات، الإعدادات، والذكاء الاصطناعي.
- **زر التحديث ⟳:**
  - الضغط العادي يمسح كاش بيانات الأدمن ويعيد تحميلها، بدون تسجيل خروج.
  - الضغط المطوّل يحدّث الصفحات والبيانات تحديثاً كاملاً.
- **زر الإشعار 📣:** يرسل إشعاراً فورياً إلى:
  - جميع المستخدمين،
  - أو من فعّل إشعارات المباريات،
  - أو تجربة على حسابك فقط.
- **صفحة الطلبات الجديدة:** مؤشرات (بانتظارك، اليوم، الأسبوع، الإيراد، متوسط وقت التفعيل)، ورسوم بيانية (14 يوماً، الباقات، طرق الدفع، أوقات الذروة)، وخط زمني مقسّم حسب الأيام.
- **إشعار فوري** عند كل طلب اشتراك جديد، وعدّاد للطلبات المنتظرة في الشريط العلوي.
- تعمل داخل التطبيق: نوافذ التأكيد والإدخال، والنسخ، واختيار الصور، وتصدير CSV (يظهر للمشاركة والحفظ)، وفتح روابط واتساب وتلجرام.

## البناء

1. ارفع مجلد `totv_admin` وملف `.github/workflows/admin_build.yml` إلى نفس مستودع التطبيق.
2. افتح Actions ثم «TOTV+ Admin — Build APK».
   - يعمل تلقائياً عند أي تغيير في `totv_admin`.
   - أو اضغط Run workflow لتشغيله يدوياً.
3. نزّل `TOTV-Admin.apk` من Artifacts.

يُوقَّع التطبيق تلقائياً بنفس مفتاح TOTV+ الموجود في المستودع.

## الإشعارات (إعداد مرة واحدة — مجاني)

يمر الإشعار عبر **Supabase Edge Function** اسمها `push`:
- مفتاح Firebase محفوظ في Secrets فقط، ولا يدخل الهاتف ولا صفحة الأدمن.
- كل طلب يُتحقَّق منه بحساب Firebase.
- البث للجميع مسموح فقط للبريدات الموجودة في `ADMIN_EMAILS`.

| الحدث | ما يحدث |
|---|---|
| مستخدم يرسل طلب اشتراك | يصلك فوراً على تطبيق الإدارة: «💰 طلب اشتراك جديد — يرجى التفعيل» بصوت خاص، والضغط عليه يفتح الطلبات |
| تكتب عنواناً ونصاً من زر 📣 | يصل لجميع مستخدمي TOTV+ بأيقونة التطبيق وكأنه صادر منه (مع صورة اختيارية) |

### 1) مفتاح Firebase (حساب خدمة)
Firebase Console ← ⚙️ Project settings ← Service accounts ← **Generate new private key** ← ينزل ملف JSON.
> هذا ملف سري. لا ترفعه إلى GitHub ولا تضعه في التطبيق.

### 2) نشر الدالة
Supabase Dashboard ← مشروعك ← **Edge Functions** ← Deploy a new function ← **Via Editor**:
- الاسم: `push`.
- الصق محتوى `supabase/functions/push/index.ts` ← Deploy.
- من إعدادات الدالة **أطفئ «Enforce JWT verification»**. الدالة تتحقق بنفسها من توكن Firebase.

### 3) Secrets
Edge Functions ← **Secrets** ← أضف:
| الاسم | القيمة |
|---|---|
| `FCM_SERVICE_ACCOUNT` | محتوى ملف JSON كاملاً |
| `ADMIN_EMAILS` | بريدك (أو عدة بريدات مفصولة بفاصلة) مثل `haedirasso@gmail.com` |

### 4) تطبيق الإدارة في Firebase (حتى يستقبل الإشعارات)
Firebase Console ← Project settings ← Add app ← Android ← Package name: `com.totv.admin` ← نزّل `google-services.json`.

الملف الجديد يحوي التطبيقين معاً (`com.totv.plus` و`com.totv.admin`). ضعه بإحدى هذه الطرق، والبناء يلتقطه تلقائياً:
- **الأسهل:** استبدل به ملف التطبيق الأساسي `android/app/google-services.json`.
- أو ضعه في `totv_admin/android/app/google-services.json`.
- أو الصق محتواه في Secret للمستودع باسم `ADMIN_GOOGLE_SERVICES_JSON`.

بدون هذا الملف يعمل التطبيق كله، لكن لن تصلك إشعارات الطلبات إلى الهاتف. يبقى عدّاد الطلبات 🔔 يعمل داخل التطبيق، ويظهر تحذير في سجل البناء.

### 5) التجربة
1. افتح التطبيق وسجّل الدخول.
2. اضغط 📣 ← اختر «تجربة — المشرفين فقط» ← إرسال. يجب أن يصلك الإشعار خلال ثوانٍ.
3. أرسل طلب اشتراك تجريبياً من تطبيق TOTV+. يجب أن يصلك «طلب اشتراك جديد».

> طريقة GitHub القديمة (`broadcast.yml`) لم تعد مطلوبة. يمكنك حذفها مع التوكن الخاص بها.

## ملاحظات

- الصفحة تُخدم داخل التطبيق على `http://localhost:8787`.
  - تسجيل الدخول بالبريد وكلمة المرور يعمل.
  - الجلسة والإعدادات محفوظة على الهاتف.
- لتحديث صفحة الأدمن مستقبلاً: استبدل `assets/admin/index.html` ثم ابنِ من جديد.
- الإشعار يصل لكل من فتح نسخة حديثة من تطبيق TOTV+ (مشترك تلقائياً في `all_users`).
